# 竜の性格診断（中日ドラゴンズ・ファンメイド）

## 起動方法
`index.html` をブラウザで開くだけで動きます。サーバーや追加ライブラリは不要です。

## GitHub Pagesで公開する方法
1. GitHubで新しいリポジトリを作成（例: `dragons-quiz`）。
2. このフォルダ内の `index.html` をリポジトリのルートにアップロード。
3. リポジトリの Settings → Pages を開く。
4. Build and deployment で `Deploy from a branch`、ブランチ `main`、フォルダ `/ (root)` を選び Save。
5. 公開後に表示されるURLを開く。

## 注意
ファン向けの非公式な娯楽コンテンツです。診断結果は選手の実際の性格を断定しません。選手名・背番号・在籍状況は公開時に公式名鑑で確認し、必要に応じて更新してください。
